# Employee Skill Tracker

## Overview

This is a simple console-based Java program designed to manage employees and their skills. The goal is for you to showcase your understanding of Object-Oriented Programming (OOP) concepts.

## Features

- Add employees with ID, name, and department.
- Add unique skills to employees.
- View all skills of a specific employee.
- View a list of all employees.

## How to Run

1. Clone this repository:
   ```bash
   git clone git@github.com:isyrafzakil/employee-skill-tracker.git
   cd employee-skill-tracker
   ```
2. Compile the Java files once completed
   ```bash
   javac *.java
   ```
3. Run the program
   ```bash
   java Main
   ```
4. Follow the menu-driven prompts to add employees, skills, and view employee data.

## Testing Your Code

- Run the `Main` class to interact with your implementation.
- Test all options in the menu.
- Bonus points: Write unit tests for the Employee and EmployeeSkillTracker classes using JUnit. Validate edge cases like adding duplicate employees or skills.

## Evaluation Criteria

- OOP Design: Clear and effective use of OOP principles, such as classes, objects, and encapsulation.
- Code Structure: Clean, readable, and well-organized code with meaningful variable and method names.
- Functionality: Does the program handle all requirements (add employee, add skill, view skills, and employees)?
- Edge Case Handling: The program should gracefully handle edge cases such as duplicate employees, skills, and invalid inputs.
